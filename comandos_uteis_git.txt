Comandos git


clonar repositório:
git clone (link do repositório do GitHub)

comitar uma mudança:
git commit m- "mensagem"

enviar o comit para o remoto:
git push

checar o status do arquivo:
git status


adicionar todos os arquivos novos:
git add .

criar branch:
git branch (Nome da branch)

trocar de branch:

git checkout (nome da branch destino)

voltar para a main:
git checkout main

puxar informacoes novas do ambiente remoto:
git pull
